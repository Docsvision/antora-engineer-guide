
[#modes]
== Режимы журналирования

ifdef::webclient[]
WARNING: Режимы и архивирование, описанные далее, относятся только к основному журналу {wc}а.
endif::webclient[]

Система поддерживает два режима журналирования, каждый режим может быть настроен независимо друг от друга или одновременно.

[cols=",,", options="header"]
|===
|Режим |Параметр конфигурации |Переключатель
|Файл |`logFile` |`enableFileLogging`
|Консоль (stdout/stderr) |`logConsole`  |`enableConsoleLogging`
|===

Оба режима ведут журнал в одинаковом JSON-формате и могут быть задействованы
ifndef::dvsupservice[]
одновременно в Windows или Linux.
endif::[]
ifdef::dvsupservice[]
одновременно.
endif::[]
// Но не в Docker

[#archivation]
== Архивирование журналов работы

По умолчанию файлы журналов архивируются каждый день или сразу, когда файл журнала достигает 300 Мб. По умолчанию, когда количество архивных файлов превышает `30`, самые старые файлы будут удаляться.

Подробнее про архивирование см. в документации по настройке системы "xref:GBL-3610@engineer:ROOT:system-logging.adoc#archivation[Архивирование журналов работы]".

[#redefine]
== Переопределение параметров

Параметры журналирования могут быть переопределены через переменные окружения. Параметры, заданные через переменные окружения, имеют приоритет над значениями, указанными в конфигурационном файле.

TIP: Подробнее про переопределение параметров с использованием переменных окружения см. в руководстве по настройке, раздел "xref:GBL-3610@engineer:ROOT:system-logging.adoc#env-vars[Переменные среды для журнала NLog]".
